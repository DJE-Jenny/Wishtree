# ✦ Wish Tree — 우리 반 소원 트리 (Netlify 버전)

링크로 들어와 닉네임을 정하고 소원을 적으면, 그 소원이 오너먼트가 되어 따뜻한 거실의 크리스마스트리에 바로 달리는 웹앱입니다.

- 오너먼트 10종 (빨간·금빛·초록 구슬, 별, 종, 지팡이사탕, 눈송이, 선물상자, 양말, 진저브레드맨)
- 1인당 개수 제한 없음. 개수가 늘수록 오너먼트가 조금씩 작아지며 트리 전체에 고르게 자동 배치됩니다.
- 소원을 달면 화면이 그 자리로 다가가 **"여기에 달렸어요"** 로 위치를 알려 줍니다. 내 오너먼트에는 금빛 테두리가 생기고, **내 오너먼트** 버튼으로 언제든 다시 찾을 수 있어요.
- 링크만 있으면 학생·학부모 등 누구나 감상하고 소원을 달 수 있습니다. 다른 사람이 단 소원은 5초 안에 나타납니다.
- **교사용 대시보드** (기본 비밀번호 `1004`): 모든 소원 보기, 숨기기·삭제, 소원 달기 잠금, CSV 다운로드
- 날짜 제한 없음. 교사가 잠그거나 지우기 전까지 계속 쓸 수 있습니다.

## 데이터는 어디에 저장되나요?

**구글 시트나 별도 데이터베이스 없이, Netlify 사이트 안의 저장소(Netlify Blobs)에 저장됩니다.**
따로 설정할 것이 없고, 사이트를 다시 배포해도 소원은 그대로 남아 있습니다.

이 저장소를 다른 선생님이 가져가 자기 Netlify에 배포하면 그 선생님만의 저장소가 새로 생깁니다. 그래서 **데이터가 서로 섞이지 않습니다.**

> ⚠️ **GitHub Pages로는 동작하지 않습니다.** GitHub Pages는 저장 기능이 없어서 데모 모드(각자 브라우저에만 저장)로 열립니다. 반드시 Netlify로 배포하세요.

| 파일 | 하는 일 |
| --- | --- |
| `public/config.js` | **이것만 고치면 됩니다.** 트리 이름 |
| `netlify/functions/api.mjs` | 소원을 저장하고 불러오는 서버 코드 (고칠 필요 없음) |
| `public/index.html` 외 | 트리 화면 |
| `public/teacher.html` | 교사용 대시보드 |
| `netlify.toml`, `package.json` | Netlify 설정 (고칠 필요 없음) |

## 1단계. GitHub에 올리기

1. GitHub에서 **New repository**로 새 저장소를 만듭니다. (예: `wish-tree`, Public 또는 Private 모두 가능)
2. 압축을 푼 폴더 **안의 내용물 전체**(`public`, `netlify` 폴더와 `netlify.toml`, `package.json`, `README.md`)를 저장소 화면에 끌어다 놓고 **Commit changes**를 누릅니다.
   - 이미 이 저장소가 GitHub에 있다면 **Fork**만 하면 됩니다.

## 2단계. Netlify에 배포하기 (처음 한 번, 3분)

1. [netlify.com](https://www.netlify.com)에 **GitHub 계정으로 가입/로그인**합니다.
2. **Add new project**(또는 Add new site) → **Import an existing project** → **GitHub**를 고릅니다.
3. 1단계에서 만든 저장소를 선택합니다.
4. 설정 화면은 `netlify.toml`이 알아서 채우므로 **그대로 두고 Deploy**를 누릅니다.
5. 1~2분 뒤 `https://무작위이름.netlify.app` 주소가 생깁니다. 이 링크(또는 QR 코드)를 학생들에게 나눠 주세요.
   - 주소를 바꾸려면: **Project configuration → Change project name** (예: `jen-wish-tree.netlify.app`)

> 연결 확인: 주소 뒤에 `/api?action=ping`을 붙여 열어 보세요. `"ok":true`가 보이면 저장 기능이 켜진 것입니다. 화면 아래에 "데모 모드" 띠가 **보이지 않으면** 정상입니다.

## 3단계. 트리 이름 바꾸기

GitHub에서 `public/config.js`를 열고 ✏️(Edit)을 눌러 `Jen`만 바꾼 뒤 **Commit changes**를 누릅니다.

```js
ownerName: "Jen",      // → "Mr. Kim" 으로 바꾸면 "Mr. Kim's Wish Tree"
```

GitHub에 저장하면 Netlify가 **자동으로 다시 배포**합니다. 1~2분 뒤 새로고침하세요. (따옴표와 쉼표는 지우지 마세요.)

## 교사용 대시보드

화면 오른쪽 위 **교사용** 버튼, 또는 `주소/teacher.html`로 들어갑니다.

- 비밀번호(기본 `1004`)를 넣으면 **숨긴 것까지 포함한 모든 소원**이 보입니다.
- **숨기기**: 트리에서만 사라지고 기록은 남습니다. **보이기**로 되돌릴 수 있어요.
- **삭제**: 완전히 지웁니다.
- **소원 달기 잠그기**: 감상은 되지만 새 소원은 달 수 없습니다.
- **CSV 다운로드**: 번호, 작성 시각, 닉네임, 오너먼트, 소원, 상태. 엑셀에서 한글이 깨지지 않게 저장됩니다. 학기 말에 한 번씩 받아 두면 백업이 됩니다.

### 비밀번호 바꾸기 (권장)

코드를 고칠 필요 없이 Netlify에서 바꿉니다. 이렇게 바꾼 비밀번호는 GitHub에 올라가지 않아요.

1. Netlify 프로젝트 → **Project configuration → Environment variables → Add a variable**
2. Key: `TEACHER_PASSWORD`, Value: `원하는 비밀번호` → 저장
3. **Deploys → Trigger deploy → Deploy project**로 한 번 다시 배포

환경 변수를 넣지 않으면 기본값 `1004`로 들어갈 수 있습니다.

## 다른 선생님에게 나눠 줄 때

- GitHub 저장소 링크를 알려 주고, 각자 **Fork → 2단계 → 3단계**를 하도록 안내하세요.
- 각자 자기 Netlify에 배포하므로 저장소(데이터)도 각자 따로 생깁니다.
- 반마다 트리를 따로 쓰고 싶다면, 같은 저장소로 Netlify 프로젝트를 반 수만큼 만들어도 됩니다. (프로젝트마다 저장소가 따로 생김)

## 자주 묻는 문제

| 증상 | 해결 |
| --- | --- |
| 화면 아래에 "데모 모드" 띠가 보여요 | GitHub Pages나 내 컴퓨터에서 파일을 직접 열었을 때 나옵니다. Netlify 주소(`…netlify.app`)로 접속하세요. |
| 이름을 바꿨는데 그대로예요 | Netlify **Deploys**에서 배포가 끝났는지 확인하고, 강력 새로고침(Ctrl+Shift+R)을 해 보세요. |
| 배포가 실패해요 | 저장소 맨 위에 `netlify.toml`, `package.json`, `public/`, `netlify/`가 바로 보이는지 확인하세요. 폴더 하나가 더 감싸고 있으면 실패합니다. |
| 학생이 "잠깐만요!" 메시지를 봐요 | 도배 방지로 같은 기기는 10초 간격으로 달 수 있어요. |
| 금칙어를 더 넣고 싶어요 | `public/api.js`와 `netlify/functions/api.mjs`의 `BAD_WORDS`에 단어를 추가하세요. |

Netlify 무료 요금제에는 월 사용량 한도가 있습니다. 학급 수업 정도는 보통 넉넉하지만, 정확한 한도는 Netlify 요금제 페이지에서 확인하세요.

## 개인정보

닉네임과 소원만 저장하고 실명·학번·연락처는 받지 않습니다. 입력 화면에도 "실명이나 전화번호는 쓰지 마세요"라고 안내합니다.
